Monitor CPU temperature in the system tray with audio alerts on overheat. Shows per-core temps and logs history to CSV. Under 5 MB RAM usage - always on in background.

## Features

- Real-time temperature displayed in system tray icon
- Configurable alert threshold with sound notification
- Per-core temperatures shown for multi-core CPUs
- Temperature history logged to CSV automatically
- Under 5 MB RAM usage - always running in background

## FAQ

**Which CPU brands are supported?**  
Intel and AMD - any CPU that exposes temperature via WMI or hardware sensors.

**Will it slow my system down?**  
No. Polling interval is configurable and the tool uses under 0.1% CPU at all times.

## Requirements

- Windows 10 / 11 (64-bit)
- Windows 10 or 11, .NET 4.8 runtime
